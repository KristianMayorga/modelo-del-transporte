# Modelo del Transporte

Notebook de Jupyter con la implementación del **modelo de transporte** (Investigación de Operaciones): optimización de la distribución de un recurso entre orígenes y destinos minimizando el costo total.

## Contenido

- `modelo_de_transporte.ipynb` — Desarrollo y solución del modelo
- `modelo/` — Recursos y datos de apoyo

## Tecnologías

- Python (Jupyter Notebook / Google Colab)
